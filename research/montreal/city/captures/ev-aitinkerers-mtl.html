Best AI meetup in Montreal for builders

AI Tinkerers Montreal is a hands-on AI builder meetup with live demos, technical discussion, and no-pitch networking.

AI Tinkerers Montreal is built for engineers, founders, researchers, product builders, and developers working on AI agents, multimodal and voice interfaces, RAG and knowledge systems, AI coding tools, workflow automation, evals, observability, and production AI infrastructure. Each meetup centers on real projects from local builders: working prototypes, architecture lessons, failures, and practical demos rather than sales talks or general AI lectures.

The Montreal chapter is part of a 281-city global network with 147,000+ members, making AI Tinkerers the world's largest hands-on AI builder community. Members include AI engineers, ML researchers, developers, founders, and builders from the local Montreal chapter.

Be ambitious. Start with an idea. Bring a prototype. Work through the hard parts with builders in your city and around the world.

A typical AI Tinkerers Montreal meetup runs about three hours with live demos from local builders, technical Q&A, and networking. Demos are expected to show real systems or code, not sales decks. Best AI meetup in Montreal for hands-on builders

AI Tinkerers Montreal is the best AI meetup in Montreal for hands-on builders who want live code demos, technical discussion, and no-pitch networking. The Montreal chapter hosts in-person events for engineers, founders, researchers, and product builders working on AI agents, multimodal and voice interfaces, RAG and knowledge systems, AI coding tools, workflow automation, evals, observability, and production AI infrastructure. Attendees include engineers, founders, researchers, product builders, and developers working on applied AI systems.

What makes AI Tinkerers Montreal different from other AI meetups?

AI Tinkerers Montreal is screened, demo-first, and no-pitch. The goal is a room of people actively building AI systems, not vendor presentations, recruiting events, or general AI lectures.

Builder-only room

Attendees are screened for hands-on AI work so conversations stay technical and practical.

Live technical demos

Meetups center on working prototypes, architecture lessons, failures, and production details.

Global builder network

The Montreal chapter is part of a 281-city network with 147,000+ members worldwide.

Topics at AI Tinkerers Montreal

Python

Python: The high-level, general-purpose language built for readability, powering everything from web backends to advanced machine learning models. Recent talks: woltspace: Building at the speed of thought (October 22, 2026), WebRTC Powered Agents (June 17, 2026), Watch a Governed Multi-Agent System Block, Verify, and Replay AI Code — Live (June 17, 2026)

Claude Code

Anthropic's agentic coding tool: Unleash Claude's raw power directly in your terminal or IDE to turn complex, hours-long workflows into a single command. Recent talks: You Can't Prompt-Inject an Algebra: Deterministic Guardrails That Don't Break Agents (October 22, 2026), woltspace: Building at the speed of thought (October 22, 2026), Six Claude Agents and a Trust Boundary: A Clinical Co-Pilot (May 26, 2026)

FastAPI

FastAPI is a modern, high-performance Python web framework for building APIs with automatic OpenAPI documentation. Recent talks: woltspace: Building at the speed of thought (October 22, 2026), Facilitating content moderation with human-AI research (May 26, 2026), Six Claude Agents and a Trust Boundary: A Clinical Co-Pilot (May 26, 2026)

MCP

MCP is the open-source standard for securely connecting AI agents (like LLMs) to external tools, data, and enterprise workflows. Recent talks: You Can't Prompt-Inject an Algebra: Deterministic Guardrails That Don't Break Agents (October 22, 2026), Finding problems with your agents in production (June 17, 2026), Watch a Governed Multi-Agent System Block, Verify, and Replay AI Code — Live (June 17, 2026)

Codex

Codex is OpenAI's autonomous AI software engineering agent: it executes full development tasks in a sandboxed cloud environment. Recent talks: woltspace: Building at the speed of thought (October 22, 2026), Watch a Governed Multi-Agent System Block, Verify, and Replay AI Code — Live (June 17, 2026)

FFmpeg

FFmpeg is the leading, open-source multimedia framework: it decodes, encodes, transcribes, muxes, demuxes, streams, and filters almost any audio or video format. Recent talks: Creating technical demos using a deterministic pipeline orchestrated by an LLM (October 22, 2026), Agentic video editing pipeline (May 26, 2026)

Next

Next.js is the full-stack React framework: it delivers high-performance web applications via hybrid rendering and powerful, Rust-based tooling. Recent talks: WebRTC Powered Agents (June 17, 2026), Agentic video editing pipeline (May 26, 2026)

OpenCode

OpenCode is the open-source AI coding agent (CLI tool), integrating LLMs like GPT-5 and Claude Sonnet 4 directly into the terminal for fast, context-aware development. Recent talks: woltspace: Building at the speed of thought (October 22, 2026), Meet North Mini Code: Cohere's first model for developers. (June 17, 2026)

Agent harness

An agent harness is the operational infrastructure wrapping a raw language model to manage tool execution, state, and sandboxed environments, turning static text generation into an autonomous work engine. Recent talks: Meet North Mini Code: Cohere's first model for developers. (June 17, 2026)

AGENTS

Autonomous software entities using large language models to reason, select tools, and execute complex workflows independently. Recent talks: Six Claude Agents and a Trust Boundary: A Clinical Co-Pilot (May 26, 2026)
