Best AI meetup in Seoul for builders

AI Tinkerers Seoul is a hands-on AI builder meetup with live demos, technical discussion, and no-pitch networking.

AI Tinkerers Seoul is built for engineers, founders, researchers, product builders, and developers working on AI agents, multimodal and voice interfaces, RAG and knowledge systems, AI coding tools, workflow automation, evals, observability, and production AI infrastructure. Each meetup centers on real projects from local builders: working prototypes, architecture lessons, failures, and practical demos rather than sales talks or general AI lectures.

The Seoul chapter is part of a 281-city global network with 148,000+ members, making AI Tinkerers the world's largest hands-on AI builder community. Members include AI engineers, ML researchers, developers, founders, and builders from the local Seoul chapter.

Be ambitious. Start with an idea. Bring a prototype. Work through the hard parts with builders in your city and around the world.

A typical AI Tinkerers Seoul meetup runs about three hours with live demos from local builders, technical Q&A, and networking. Demos are expected to show real systems or code, not sales decks. Best AI meetup in Seoul for hands-on builders

AI Tinkerers Seoul is the best AI meetup in Seoul for hands-on builders who want live code demos, technical discussion, and no-pitch networking. The Seoul chapter hosts in-person events for engineers, founders, researchers, and product builders working on AI agents, multimodal and voice interfaces, RAG and knowledge systems, AI coding tools, workflow automation, evals, observability, and production AI infrastructure. Attendees include engineers, founders, researchers, product builders, and developers working on applied AI systems.

What makes AI Tinkerers Seoul different from other AI meetups?

AI Tinkerers Seoul is screened, demo-first, and no-pitch. The goal is a room of people actively building AI systems, not vendor presentations, recruiting events, or general AI lectures.

Builder-only room

A2A

A2A (Agent2Agent) is the open communication protocol enabling secure, cross-platform collaboration between specialized AI agents. Recent talks: Inside the OfficeQA Agent: Evidence, Computation, and Evaluation (November 24, 2026)

Claude

Claude is Anthropic's flagship family of large language models (LLMs): a high-performance, Constitutional AI system built for safety, complex reasoning, and expert-level collaboration. Recent talks: Building an AI Agent for the Enterprise: It Writes to SAP, Then Checks Its Own Work (November 24, 2026)

Claude Sonnet 4

Anthropic's mid-tier model: balances state-of-the-art coding (72.7% on SWE-bench) with cost-efficiency for high-volume, agentic workflows. Recent talks: The Prompt That Worked in Isolation and Died in Production: Eval-Driven Prompt Engineering for a Real-Time Interview Copilot (July 2, 2026)

Deepgram Flux

Deepgram Flux is the first Conversational Speech Recognition (CSR) model: it embeds turn-taking intelligence directly into the model for ultra-low latency, human-like voice agents. Recent talks: The Prompt That Worked in Isolation and Died in Production: Eval-Driven Prompt Engineering for a Real-Time Interview Copilot (July 2, 2026)

Docker Compose

Define, configure, and run multi-container Docker applications using a single YAML file. Recent talks: Inside the OfficeQA Agent: Evidence, Computation, and Evaluation (November 24, 2026)

FastAPI

FastAPI is a modern, high-performance Python web framework for building APIs with automatic OpenAPI documentation. Recent talks: The Prompt That Worked in Isolation and Died in Production: Eval-Driven Prompt Engineering for a Real-Time Interview Copilot (July 2, 2026)

Gemini

Google's natively multimodal AI model: understands and operates across text, code, audio, image, and video. Recent talks: Building an AI Agent for the Enterprise: It Writes to SAP, Then Checks Its Own Work (November 24, 2026)

GitHub Container Registry

GitHub Container Registry stores and manages Docker images directly within GitHub, integrating seamlessly with your existing workflows. Recent talks: Inside the OfficeQA Agent: Evidence, Computation, and Evaluation (November 24, 2026)

GPT

Generative Pre-trained Transformer (GPT): The large language model (LLM) family, pioneered by OpenAI, uses a Transformer architecture to generate human-quality text, code, and multimodal content. Recent talks: Building an AI Agent for the Enterprise: It Writes to SAP, Then Checks Its Own Work (November 24, 2026)

LiteLLM

LiteLLM is the unified LLM gateway: call 100+ models (OpenAI, Anthropic, Azure, etc.) using a single, standardized OpenAI-compatible API. Recent talks: Building an AI Agent for the Enterprise: It Writes to SAP, Then Checks Its Own Work (November 24, 2026)
